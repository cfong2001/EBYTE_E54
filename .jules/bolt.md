## 2024-05-18 - Optimized Array Operations and Math Calls
**Learning:** In CircuitPython, nested loops containing byte iterations (`for i in range(len(buffer))`) and heavy floating-point operations (`math.sqrt()`) cause significant CPU usage and memory allocation overhead. Manual loop iterators and `try: buffer.index()` are orders of magnitude slower than built-in standard library C bindings like `buffer.find()`. Additionally, comparing squared values (`x**2 + y**2 < 90000`) completely bypasses the computational cost of `math.sqrt()`.
**Action:** When working in embedded Python constraints, always replace manual loops and `.index()` error catching with `buffer.find()` or `.split()`. For euclidean distance checks (e.g., target tracking), compare the squared result of bounding box dimensions instead of calculating the direct hypotenuse using the square root unless absolutely required for display purposes.
