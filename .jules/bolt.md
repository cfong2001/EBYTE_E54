## 2023-10-27 - Optimized Presentation Layer and Arithmetic
**Learning:** Monolithic rendering systems and redundant flash EEPROM writes during tight loops create micro-stutter in the UI. Floating point divisions and double-promotions inside fast loops reduce rendering FPS. String heap allocation in high-frequency functions causes heavy heap fragmentation leading to pauses.
**Action:** Replace `String` loops with static `char` array buffers and `snprintf`. Use `std::clamp` and `std::lround`. Always use explicit multiplication by reciprocals instead of float divisions, and suffix literals with `f` to avoid single-to-double implicit promotions. Implement deferred write-backs on state changes via `flagDirty()` instead of synchronous saves. Implement `IView` to cleanly manage the State pattern for distinct render screens.
