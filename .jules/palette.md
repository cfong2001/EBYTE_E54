## 2026-05-19 - [Progressive Visual Feedback with sinf()]
**Learning:** Hard-coded binary blinking loops (e.g. alternating states based on `millis() % 2 == 0`) create visual fatigue. **Action:** Replace abrupt toggle UI elements with smooth sinewave oscillators. Example: `float pulse = (sinf(millis() / 150.0f) + 1.0f) * 0.5f;` to generate a smooth 0-1 scalar, and apply it to `sprite.alphaBlend` for color transitions and radius offsets for pulsing animations. Ensure you utilize `sinf` rather than double-precision `sin` to avoid computational overhead on the ESP32.

## 2024-06-20 - Dynamic Centering on Adafruit_GFX Displays
**Learning:** While `TFT_eSPI` supports `textWidth()`, `Adafruit_GFX` (and specifically `Adafruit_SSD1306`) does not. Attempting to use `textWidth()` on Adafruit screens will fail compilation. Centering dynamically generated text (or handling scaling) requires using `getTextBounds` to extract the width (`w`) before computing coordinates, otherwise text becomes off-center or breaks.
**Action:** When working with Adafruit displays, always use `getTextBounds(string, 0, 0, &x1, &y1, &w, &h)` to extract the width (`w`) for centering calculations (e.g., `(screenWidth - w) / 2`).
