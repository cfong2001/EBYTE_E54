## 2024-07-24 - Dynamic Centering for transient WIFI overlays
**Learning:** Hardcoded coordinates for text strings in transient UI states (like temporary overlays during password generation) break visual alignment, especially when accessibility settings like text scaling are modified or different strings are presented. Left-aligning them when other elements are centered creates a jarring visual inconsistency.
**Action:** Use responsive measurement functions like `textWidth()` combined with boundary calculations (e.g., `(tft.width() - textWidth) / 2`) to dynamically center text. When calculating the width of concatenated dynamic strings, sum the `textWidth()` of individual components (e.g., `sprite.textWidth("NEW PASS: ") + sprite.textWidth(newPass.c_str())`) instead of instantiating new Arduino `String` objects to avoid heap allocation overhead.
