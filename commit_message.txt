🎨 Palette: [UX improvement] Fix hardcoded alignment for transient UI screens

💡 What: Replaced hardcoded `sprite.setCursor(10, 100);` placements on transient action screens (like "WIPING PREFERENCES...", "REGENERATING WIFI PASSWORD...", and "NEW PASS: ") with dynamic centering using `textWidth()`.
🎯 Why: When accessibility settings like text scaling are modified, hardcoded X coordinates break visual alignment, resulting in ragged, off-center text blocks. Dynamic calculation ensures text remains perfectly centered regardless of the chosen scale or string length.
📸 Before/After: Visual alignment during system resets and credential generation is now consistently centered on the TFT display.
♿ Accessibility: Supports varied text sizes without breaking the UI layout.
